First launch on macOS / Первый запуск на macOS

Русский

Почему macOS показывает предупреждение?
Live Transcription — независимый проект с открытым исходным кодом. Для подписи сертификатом Developer ID и нотарификации установщика требуется платное членство Apple Developer Program, которого у проекта пока нет. Поэтому Apple не может автоматически подтвердить разработчика. Это системное предупреждение само по себе не означает, что macOS обнаружила вредоносное ПО.
  1. При обновлении сначала закройте старую версию: Live Transcription → Завершить (⌘Q). Открытое приложение macOS заменить не даст.
  2. Перетащите Live Transcription в папку Applications / Программы и при обновлении выберите «Заменить».
  3. Запустите скопированное приложение один раз и закройте предупреждение.
  4. Откройте Системные настройки → Конфиденциальность и безопасность.
  5. Прокрутите вниз до раздела «Безопасность» и нажмите «Всё равно открыть» рядом с Live Transcription.
  6. Подтвердите действие паролем или Touch ID и нажмите «Открыть».

Это подтверждение требуется только при первом запуске каждой новой версии. Не отключайте Gatekeeper целиком и не вводите команды для снятия системной защиты.

English

Why does macOS show a warning?
Live Transcription is an independent open-source project. Signing with a Developer ID certificate and notarizing the installer require a paid Apple Developer Program membership, which the project does not currently have. Apple therefore cannot automatically verify the developer. This system warning does not by itself mean that macOS detected malware.
  1. When updating, quit the old version first: Live Transcription → Quit (⌘Q). macOS cannot replace an app that is open.
  2. Drag Live Transcription to Applications; when updating, choose Replace.
  3. Try to open the copied app once, then close the warning.
  4. Open System Settings → Privacy & Security.
  5. Scroll down to Security and click Open Anyway next to Live Transcription.
  6. Authenticate with your password or Touch ID, then confirm Open.

This confirmation is required only on the first launch of each new version. Do not disable Gatekeeper globally or run commands that remove system protection.
