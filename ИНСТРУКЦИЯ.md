# Расшифровка записей встреч

Инструмент делает из видео- или аудиозаписи встречи два документа:

- **полный текст**, разбитый на абзацы. Каждый абзац начинается с таймкода `[чч:мм:сс]`, поэтому любое место легко найти в записи и переслушать;
- **выжимку** (по желанию): решения, договорённости с ответственными и сроками, открытые вопросы, ключевые факты и ход встречи по темам, везде с таймкодами.

Расшифровка идёт **локально на вашем компьютере**: запись никуда не отправляется. Наружу уходит только текст расшифровки, и только если вы сами попросили выжимку (подробнее в разделе «Выжимка и правила использования Claude»).

Скорость: 3 часа записи обрабатываются примерно за 10 минут на видеокарте NVIDIA. На компьютере без NVIDIA работа идёт на процессоре и занимает в несколько раз дольше, но тоже работает.

## Аккаунты

Инструмент не привязан ни к чьему аккаунту:

- для расшифровки аккаунт не нужен вообще. Модель Whisper скачивается при установке с Hugging Face без входа;
- выжимку делает Claude Code, установленный **у вас**, под **вашим** аккаунтом. Инструмент запускает его без ваших личных настроек, хуков и MCP-серверов и не сохраняет сессию в истории.

## Что нужно

- Windows 10 или 11;
- около 4 ГБ свободного места и интернет на время установки;
- `uv`, менеджер Python, через него ставится всё остальное;
- только для выжимки: Claude Code, в котором вы вошли в свой аккаунт. Проверка: команда `claude --version` в терминале должна вывести номер версии.

## Установка

1. Распакуйте архив в папку, например в `C:\bin\transcribe`. Путь может быть любым, но после установки папку не перемещайте (см. «Если что-то не работает»).
2. Если `uv` ещё не установлен, установите его в PowerShell:
   ```
   winget install --id astral-sh.uv
   ```
   После установки откройте новое окно терминала, чтобы `uv` появился в PATH.
3. Запустите `setup.cmd` из папки инструмента двойным щелчком или из терминала. Он скачает в эту папку:
   - собственный Python 3.12;
   - пакеты вместе с библиотеками NVIDIA, около 1,5 ГБ;
   - модель Whisper `large-v3-turbo`, около 1,6 ГБ.

   В самом начале он спросит, добавить ли инструмент в меню «Отправить» (см. «Через меню „Отправить“»). Ответ `Y` или `N`; передумать можно потом в любой момент.

   Занимает 5–15 минут. В конце появится строка `Setup complete.`

Системный Python и другие программы установка не трогает: всё лежит внутри папки инструмента.

## Как пользоваться

### Перетаскиванием (проще всего)

Перетащите один или несколько файлов записи в Проводнике:

| На этот файл | Что получится |
|---|---|
| `drop-text.cmd` | полный текст (`.txt`) и субтитры (`.srt`). Всё локально |
| `drop-text-summary.cmd` | то же плюс выжимка (`.summary.md`). Перед отправкой текста в Claude скрипт спросит, можно ли отправлять содержание этой встречи в Claude |

Готовые файлы появляются в подпапке с именем записи рядом с ней (см. «Что получается»). Окно с ходом работы закроется после нажатия любой клавиши.

### Через меню «Отправить» (по желанию)

Если при установке вы ответили `Y`, папку инструмента держать открытой не нужно: правый щелчок по записи → «Отправить» → «Расшифровать (текст)» или «Расшифровать (текст и выжимка)». Это те же два скрипта, что и для перетаскивания. В Windows 11 пункт «Отправить» находится в «Показать дополнительные параметры» (или Shift + правый щелчок).

Включить или убрать меню позже: запустите `send-to-menu.cmd` и выберите `A` (добавить) или `R` (убрать). Он меняет только эти два ярлыка в вашей папке «Отправить», больше ничего.

### Из терминала

```
C:\bin\transcribe\transcribe.cmd "D:\Записи\встреча.mp4" --language ru
C:\bin\transcribe\transcribe.cmd "D:\Записи\встреча.mp4" --language ru --summary --srt
C:\bin\transcribe\transcribe.cmd "D:\Записи\встреча.txt" --summary
```

Последняя команда делает выжимку по уже готовому тексту, без повторной расшифровки.

Параметры:

| Параметр | Что делает |
|---|---|
| `--language ru` | язык встречи: `ru`, `de`, `en` и т.д. Без него язык определяется по первым 30 секундам; для встреч на смешанных языках лучше указать основной |
| `--summary` | сделать выжимку через Claude |
| `--srt` | записать субтитры с точными таймингами |
| `--out-dir ПАПКА` | куда класть результаты (по умолчанию подпапка с именем записи рядом с ней) |
| `--cpu` | работать на процессоре, даже если есть видеокарта |
| `--terms ФАЙЛ` | дополнительный словарь терминов для этой встречи (см. «Словарь терминов») |
| `--no-terms` | расшифровать без словарей |
| `--no-filter` | не убирать «галлюцинации» Whisper (см. ниже), оставить всё как есть |
| `--force` | перезаписать уже готовые результаты (см. «Повторный запуск») |

Подходят все обычные форматы: mp4, mkv, mov, webm, mp3, m4a, wav и другие.

## Что получается

Для каждой записи рядом с ней создаётся подпапка с тем же именем, и все результаты лежат в ней:

```
D:\Записи\встреча.mp4
D:\Записи\встреча\встреча.txt
D:\Записи\встреча\встреча.srt
D:\Записи\встреча\встреча.summary.md
```

Если делать выжимку по готовому `.txt`, она появится рядом с этим `.txt`.

- **`<имя>.txt`**: полный текст. Новый абзац начинается примерно каждые 30 секунд речи (по концу предложения) или после паузы. Говорящие не подписаны. Имена, фамилии и технические термины распознаются с ошибками чаще обычных слов.
- **`<имя>.srt`**: субтитры, чтобы пересмотреть спорный кусок с текстом поверх видео. Автоматически плеер берёт субтитры только из папки с видео, поэтому подключите их вручную (в VLC: «Субтитры» → «Добавить файл субтитров») или переложите `.srt` к видео.
- **`<имя>.summary.md`**: выжимка, целиком на языке встречи. Для русской встречи разделы такие: «Коротко», «Решения», «Договорённости и задачи», «Открытые вопросы и риски», «Ключевые факты», «Ход встречи». Claude велено ничего не додумывать и помечать места, где распознавание сомнительно. **Перед тем как пересылать выжимку, сверьте ключевые места по таймкодам с полным текстом**: вы отвечаете за то, что отправляете.

Как устроена выжимка, задаёт файл `summary_prompt.md`, его можно править.

### Повторный запуск

Готовые результаты не затираются, поэтому текст, который вы поправили руками, не пропадёт:

- если `<имя>.txt` уже есть, запись заново не расшифровывается. Если при этом нужна выжимка, а её ещё нет, она делается по имеющемуся тексту (удобно: сначала `drop-text.cmd`, потом, если нужно, `drop-text-summary.cmd`);
- если `<имя>.summary.md` уже есть, выжимка заново не делается;
- чтобы переделать, добавьте `--force`. Только выжимку: `transcribe.cmd <имя>.txt --summary --force`.

Если расшифровку прервать (закрыть окно, сбой), недописанный `.txt` не остаётся, и следующий запуск начнёт её заново.

### «Галлюцинации» Whisper

Whisper учился на субтитрах к видео, поэтому в паузах и шуме иногда «слышит» фразы, которых не было: «Продолжение следует...», «Субтитры сделал ...», «Спасибо за просмотр!». Бывает и зацикливание, когда одна фраза повторяется много раз подряд. Инструмент это убирает:

- короткие фрагменты с такими типовыми фразами выбрасываются. Обычная речь со словом «субтитры» остаётся;
- повтор внутри фрагмента («и так далее, и так далее, и так далее, и так далее») сворачивается до одного раза;
- фрагмент, который слово в слово повторяет предыдущий, выбрасывается. Короткие реплики вроде «Да.» не трогаются;
- каждое 30-секундное окно распознаётся без опоры на предыдущий текст, чтобы одна ошибка не тянулась дальше по записи.

В конце работы инструмент пишет, сколько всего убрано (строка `Filtered: ...`). Если кажется, что пропало нужное, перезапустите с `--no-filter` и сравните.

## Словарь терминов

Whisper часто искажает названия, фамилии и жаргон: «Джира» вместо Jira, «кубернетис» вместо Kubernetes, ошибки в фамилиях коллег. Словарь подсказывает модели, как эти слова пишутся правильно.

- **`terms.txt`**: общий словарь команды. Входит в архив для команды, но не в git-репозиторий, поэтому туда можно писать названия продуктов и проектов компании. Если файла нет, создайте его рядом с `transcribe.py`.
- **`terms.local.txt`**: ваш личный словарь, например фамилии коллег или названия ваших проектов. В архив для команды **не попадает**. Если файла нет, просто создайте его рядом с `terms.txt`.
- **`--terms ФАЙЛ`**: словарь для конкретной встречи, например участники и темы. Параметр можно указать несколько раз.

Формат один и тот же во всех файлах: один термин на строку, ровно в том написании, которое должно получиться. После `#` идёт комментарий.

```
Jira
Kubernetes
Иванов            # фамилии тоже можно
```

Правила:

- **Добавляйте только то, что реально распознаётся неправильно.** Модель может иногда вставить подсказанное слово туда, где его не произносили.
- **Держите список коротким.** Whisper читает не больше 223 токенов, это примерно 60–100 терминов. Остальное отбрасывается. При запуске инструмент показывает, сколько терминов и токенов использовано, и предупреждает, если список слишком длинный.
- **При переполнении первыми сохраняются самые конкретные словари:** сначала `--terms`, потом `terms.local.txt`, потом `terms.txt`.

## Выжимка и правила использования Claude

Выжимка отправляет текст расшифровки в Claude под вашим аккаунтом. Поэтому для неё действуют правила, под которыми вы пользуетесь Claude: правила вашей организации по работе с ИИ, если это рабочий аккаунт, и условия использования Anthropic. Прежде чем делать выжимку, проверьте, что содержание встречи можно отправлять. Обычно нельзя отправлять:

- персональные данные сверх нужного, и **никогда** данные о здоровье и другие особые категории;
- пароли, ключи и другие учётные данные;
- конфиденциальные материалы клиентов и партнёров (цены, договоры, материалы под NDA), если правила или договор не разрешают их обработку в Claude;
- частные и личные разговоры, если аккаунт рабочий. Для них делайте только локальный текст через `drop-text.cmd`.

Если сомневаетесь, не делайте выжимку: локальный текст получается и без неё. Если что-то недопустимое всё-таки ушло в Claude, действуйте так, как требуют правила вашей организации.

## Если что-то не работает

| Сообщение | Что делать |
|---|---|
| `The environment is missing. Run setup.cmd ...` | запустите `setup.cmd` |
| `uv not found on PATH` | установите `uv` (шаг 2 установки) и откройте новый терминал |
| Инструмент перестал запускаться после переноса папки | окружение привязано к пути папки: запустите `setup.cmd` ещё раз в новом месте. Модель повторно не скачивается. На вопрос про меню «Отправить» ответьте `Y`, чтобы ярлыки указывали на новое место |
| `Transcript exists, kept` | запись уже расшифрована, текст не тронут. Переделать: добавьте `--force` |
| `GPU not usable ... falling back to CPU` | видеокарты NVIDIA нет или драйвер старый. Работа продолжается на процессоре, только медленнее |
| `Claude Code CLI (claude) not found` | установите Claude Code и войдите в свой аккаунт. Полный текст при этом всё равно создаётся |
| `Summary FAILED` | откройте терминал, выполните `claude` и проверьте, что вы вошли в аккаунт. Затем повторите: `transcribe.cmd <имя>.txt --summary` |
| Текст на неправильном языке | укажите язык явно: `--language ru` |
